# Руководство по запуску «НарядAI» на Windows 11

Система «НарядAI» кроссплатформенна и поддерживает 4 сценария запуска на Windows 11.

---

## ⚡ Вариант 1: Без установки на Windows (Прямой доступ по локальной сети)

Если сервер уже запущен на другом компьютере, а ваш ПК с Windows 11 (или смартфон) подключён к той же Wi-Fi сети / роутеру:
1. На Windows 11 откройте любой браузер (Chrome, Edge, Firefox, Yandex).
2. Перейдите по адресу, который скрипт запуска напечатал на компьютере с сервером
   (строка вида `http://192.168.x.x:8000`, рядом — QR-код для телефона).
3. Сайт откроется сразу, без необходимости устанавливать Python или Node.js на Windows!
4. **Учётные записи для демо (ПИН у всех: 1234):**
   - **Мастер смены:** `master1` (Исмаилов М.К.)
   - **Слесарь (свободен):** `ahmetov` (Ахметов Е.С.)
   - **Слесарь (брак/повторы):** `serikov` (Сериков Д.К.)
   - **Главный механик:** `boss` (Сагинтаев Б.А.)

---

## 🚀 Вариант 2: Запуск в 1 клик через `run_windows.bat` (Нативно на Windows 11)

### 1. Подготовка
Ничего ставить заранее не обязательно. Скрипт сам проверит, есть ли **Python 3.11+** и
**Node.js 18+**, а если их нет — предложит установить через `winget` (он встроен в Windows 11):
- Python 3.12 — загрузка ~25 МБ, права администратора не нужны;
- Node.js LTS — загрузка ~30 МБ, Windows покажет окно UAC — подтвердите его.

Node.js нужен только для первой сборки интерфейса (`frontend\dist`). Если собранный `dist`
уже лежит в папке проекта, Node.js не нужен вовсе.

Можно поставить всё заранее вручную (PowerShell):
```powershell
winget install -e --id Python.Python.3.12
winget install -e --id OpenJS.NodeJS.LTS
```
> ℹ️ Команда `python` в «чистой» Windows 11 — это пустой ярлык Microsoft Store, а не Python.
> Скрипт такой ярлык игнорирует и ищет настоящий Python сам (через `py`, `PATH` и папки установки).

### 2. Запуск
- Скопируйте папку проекта на диск Windows (например, в `C:\Projects\naryad-ai`).
- Дважды кликните по файлу **`run_windows.bat`**.
  Файл скачан из интернета, поэтому Windows может показать «Windows защитила ваш компьютер» —
  нажмите «Подробнее» → «Выполнить в любом случае».
- Скрипт автоматически:
  1. Найдёт Python, создаст виртуальное окружение `backend\.venv` и установит зависимости.
  2. Сгенерирует базу данных `backend\naryad.db` с 600+ нарядами за 92 дня (около минуты).
  3. Соберёт веб-интерфейс `frontend\dist`, если он ещё не собран.
  4. Запустит сервер и откроет браузер на `http://localhost:8000`, как только сервер ответит.
- Первый запуск занимает несколько минут, повторные — несколько секунд: готовые шаги пропускаются.
- Остановить сервер — `Ctrl+C` в окне скрипта.

Параметры (передаются прямо в `run_windows.bat`):

| Параметр | Что делает |
|---|---|
| `-Port 8001` | Запустить на другом порту (если 8000 занят) |
| `-LocalOnly` | Слушать только этот ПК (`127.0.0.1`); телефон по Wi-Fi подключиться не сможет |
| `-NoBrowser` | Не открывать браузер автоматически |

Пример (в папке проекта, в PowerShell или cmd): `.\run_windows.bat -LocalOnly -Port 8001`.
Если «НарядAI» уже запущен, повторный запуск просто откроет его в браузере.

### 3. Открыть с телефона (тот же Wi-Fi)
В окне скрипта печатаются адрес вида `http://192.168.x.x:8000` и QR-код. При первом запуске
Windows спросит про брандмауэр для Python — отметьте **«Частные сети»** и нажмите «Разрешить доступ».
(Если запустить `run_windows.bat` от имени администратора, скрипт сам добавит правило для порта.)

## 🐧 Вариант 3: Запуск через WSL2 (Ubuntu в Windows 11 — Рекомендуется для разработчиков)

Windows 11 имеет встроенную поддержку WSL2 (полноценное ядро Linux). Это самый стабильный способ работы.

1. Откройте **Терминал Windows** (PowerShell от имени администратора) и установите WSL, если ещё не установлен:
   ```powershell
   wsl --install
   ```
2. Откройте Ubuntu внутри Windows 11 (`wsl`).
3. Перейдите в папку проекта:
   ```bash
   cd /mnt/c/Projects/naryad-ai
   # или склонируйте репозиторий прямо внутрь WSL:
   # git clone ...
   ```
   > ⚠️ Не запускайте один и тот же каталог и из Windows (`run_windows.bat`), и из WSL (`run.sh`):
   > у них разные виртуальные окружения `backend\.venv`. Для WSL лучше держать копию проекта
   > внутри Linux (`~/naryad-ai`) — так и быстрее.
4. Запустите скрипт:
   ```bash
   ./run.sh
   ```
5. В Windows 11 откройте браузер: `http://localhost:8000`. Порт пробрасывается из WSL2 в Windows автоматически!

---

## 🐳 Вариант 4: Запуск через Docker Desktop на Windows 11

1. Установите [Docker Desktop для Windows](https://www.docker.com/products/docker-desktop/) (с бэкендом WSL2).
2. Запустите Docker Desktop.
3. В папке проекта выполните в терминале:
   ```powershell
   docker compose up --build
   ```
4. Откройте `http://localhost:8000`.

## 🛠 Если что-то не работает

| Симптом | Причина и решение |
|---|---|
| «Python не найден», хотя он установлен | В новом окне терминала `python` может по-прежнему указывать на заглушку Store. Скрипт её обходит; если не помогло — переустановите Python (`winget install -e --id Python.Python.3.12`) и запустите `run_windows.bat` снова |
| «Выполнение сценариев отключено в этой системе» | Запускайте через `run_windows.bat` — он включает обход политики только для этого запуска. Не запускайте `run_windows.ps1` двойным кликом |
| «Windows защитила ваш компьютер» (SmartScreen) | «Подробнее» → «Выполнить в любом случае». Или один раз: `Get-ChildItem -Recurse . \| Unblock-File` |
| Ошибка при установке зависимостей | Нужен интернет (pip скачивает пакеты). Используйте Python 3.12: на самых новых версиях Python у части пакетов может не быть готовых сборок |
| `DLL load failed … Политика управления приложениями заблокировала этот файл` | Это **Smart App Control** — защита Windows 11: она блокирует неподписанные скомпилированные модули (`.pyd`) без «репутации». Скрипт сам заменяет заблокированный SQLAlchemy его официальной сборкой на чистом Python, защиту не трогает. Если блокируется что-то ещё — запустите через WSL2 или Docker (Варианты 3 и 4) либо откройте сервер с другого ПК (Вариант 1). Отключение Smart App Control необратимо (вернуть можно только переустановкой Windows) — это решение за вами, скрипт его не принимает |
| Порт 8000 занят другой программой | Запустите на другом порту: `.\run_windows.bat -Port 8001` |
| Открывается страница `/docs`, а интерфейса нет | Не собран `frontend\dist`: установите Node.js LTS и запустите `run_windows.bat` снова |
| Телефон не открывает страницу | Тот же Wi-Fi; брандмауэр — «Частные сети» (см. выше); в гостевых сетях с изоляцией клиентов не работает |
| Хочется начать с чистой базы | Остановите сервер и удалите `backend\naryad.db` — при следующем запуске она создастся заново |
| Нужно «с нуля» переустановить окружение | Удалите папку `backend\.venv` (и при необходимости `frontend\node_modules`, `frontend\dist`) |
