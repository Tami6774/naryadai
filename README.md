# «НарядAI»: Интеллектуальная система выдачи и контроля нарядов

> **Организатор кейса:** АО «Костанайские Минералы»  
> **Мероприятие:** Республиканский хакатон «Qostanai Industry Hackathon 2026»  
> **Слоган:** *«Наряд выдан — ИИ на контроле»*

---

## 📌 О проекте

«НарядAI» переводит весь цикл выдачи, исполнения и контроля ремонтно-технических нарядов предприятия в цифровой вид:
- **Мастер смены** выдаёт наряд со смартфона за ≤ 1 минуту и ≤ 6 нажатий с ИИ-подсказкой исполнителя.
- **Исполнители (слесари, электрики, сварщики)** получают push-уведомления со звуком, управляют статусами кнопками, адаптированными под рабочие перчатки, прикладывают фото и списывают материалы.
- **ИИ-контролёр:**
  1. Постоянно отслеживает дедлайны (напоминание за 30 мин, эскалация не принятых нарядов за 3/10 мин, уведомления о просрочке обоим).
  2. Проверяет качество закрытия наряда (соответствие работ, фото «до/после», сравнение списанных ТМЦ с нормами расхода).
  3. Формирует понятный объективный рейтинг рабочих по 5 взвешенным факторам.
  4. Анализирует историю за 3 месяца и выявляет «узкие места» и аномалии (Конвейер К-3, поломки после ППР, ночные смены).

## 🚀 Быстрый запуск

**Требования:** Python 3.11+ (с модулем `venv`). Node.js нужен только для пересборки
интерфейса — в архиве уже есть собранный `frontend/dist`.

| ОС | Команда |
|---|---|
| Linux / macOS | `./run.sh` |
| Windows 11 | двойной клик по `run_windows.bat` (или `run_windows.ps1` в PowerShell) |
| Docker | `docker compose up --build` |

При первом запуске скрипт сам создаёт виртуальное окружение, ставит зависимости и
генерирует демонстрационную базу за 3 месяца (≈ 1 мин). Затем в терминале появятся
**адрес для телефона и QR-код**.

- Веб-панель на ПК: **http://localhost:8000**
- Документация API (Swagger): **http://localhost:8000/docs**

### Режим разработки (Hot Reload)
```bash
# Терминал 1 (бэкенд):
cd backend && .venv/bin/uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
# Терминал 2 (фронтенд):
cd frontend && npm install && npm run dev      # http://localhost:3000 (прокси на :8000)
```

## 📱 Вход с телефона

Сервер слушает все сетевые интерфейсы, поэтому телефон в **той же сети Wi-Fi** открывает
систему по IP компьютера:

1. Запустите сервер — в терминале будет строка вида `http://192.168.x.x:8000` и QR-код.
   Тот же адрес и QR-код показаны на странице входа, если открыть её на ПК (`localhost:8000`).
2. Отсканируйте QR-код камерой телефона или введите адрес в браузере (Chrome / Safari).
3. Войдите под учёткой исполнителя или мастера (см. ниже).

**Приложение для Android (APK):** кнопка «Скачать установочный APK» на странице входа
(файл `backend/media/naryad-ai.apk`, копия — `naryad-ai.apk` в корне). После установки
нажмите «Изменить» в строке «Сервер» на экране входа и укажите адрес из терминала.

**Если телефон не открывает страницу:**
| Причина | Что сделать |
|---|---|
| Телефон в другой сети / мобильном интернете | Подключить к тому же Wi-Fi, что и ПК |
| Брандмауэр Windows | Разрешить Python во всплывающем окне (частные сети) или запустить `run_windows.bat` от имени администратора — скрипт сам добавит правило для порта 8000 |
| Брандмауэр Linux | `sudo ufw allow 8000/tcp` или `sudo firewall-cmd --add-port=8000/tcp --permanent && sudo firewall-cmd --reload` |
| Гостевая сеть с изоляцией клиентов | Использовать обычную сеть или раздать точку доступа с телефона/ПК |
| Docker | Задать `PUBLIC_BASE_URL=http://<IP-ПК>:8000`, чтобы показывался адрес ПК, а не контейнера |

> Голосовой ввод через кнопку 🎤 в браузере работает на ПК (`localhost`). На телефоне по
> `http://` браузер блокирует микрофон — используйте кнопку микрофона на клавиатуре телефона.

## 🎯 Сквозной сценарий защиты (7 минут, 9 шагов)

1. **Панель смены:** Мастер открывает панель смены — видит свободного слесаря Ахметова (🟢) и занятого Серикова (🟡).
2. **Выдача аварийного наряда:** Мастер фотографирует течь масла на насосе ГрАТ-1400 №1, создаёт аварийный наряд в 4 тапа. ИИ сразу предлагает Ахметова с обоснованием («свободен, слесарь, рейтинг 92»).
3. **Реакция исполнителя в реальном времени:** В окне/телефоне Ахметова раздаётся звуковой сигнал. Ахметов жмёт «Принять» → «Начать исполнение». У мастера статус меняется мгновенно (≤ 1 сек через WebSocket).
4. **Очередь и контроль сроков:** Выдаётся наряд с коротким дедлайном. Исполнитель ставит его в очередь. При наступлении срока ИИ отправляет уведомление о просрочке обоим.
5. **Закрытие первого наряда:** Ахметов завершает ремонт, указывает шифр `Г-01`, списывает 2 манжеты и 10 л масла, прикладывает фото «после» и жмёт «Отправить на проверку ИИ».
6. **Оценка ИИ:** ИИ сравнивает фото до/после, проверяет расход по технологической карте и ставит **92/100 (Принято)**. Мастер видит отчёт и подтверждает закрытие.
7. **Проверка нарушений ИИ:** Закрывается наряд без фото и с завышением расхода масла в 4 раза → ИИ ставит вердикт **«Требует доработки»** с детальным штрафом и возвращает в работу.
8. **Отчёт за смену и рейтинг:** Демонстрация таблицы с прозрачным расчётом баллов рабочих и бригад.
9. **ИИ-Аналитика за 3 месяца:** Переход в раздел аномалий — ИИ показывает:
   - Конвейер К-3 (ломается в 3.2 раза чаще нормы, 70% отказов — подшипник М-02).
   - Дробилка КМД-1750 (поломки через 2–5 дней после ППР).
   - Повторные отказы Серикова и перерасход материалов Ковалёва.

## 🧪 Запуск автоматических тестов

```bash
cd backend
.venv/bin/python -m unittest discover -s tests -p "test_*.py"     # 36 тестов
```
Тестовый набор валидирует:
- Все 10 статусов жизненного цикла (`test_lifecycle.py`);
- Очередь нарядов и переходы исполнителей;
- Срабатывание штрафов ИИ при незаполненных фото и завышенных материалах;
- Экспорт сменного рапорта, рейтинга рабочих и отчёта по ТМЦ в формат Excel (`test_exports_nlp.py`);
- Формирование официальной печатной формы наряда с ИИ-заключением;
- Автономный ИИ NLP-модуль подсказки шифров дефектов и семантической валидации.
- Экранирование пользовательского ввода в печатной форме (защита от XSS);
- Приведение сроков с часовым поясом к локальному времени сервера (`test_schemas.py`);
- Демо-режим и запрет запуска с секретом JWT по умолчанию (`test_config.py`);
- Наряд на бригаду, история оборудования, отчёты за период с фильтрами, простои и прогноз отказов
  через HTTP API на свежей демо-базе (`test_case_features.py`);
- Языковая/мультимодальная модель: разбор ответа, переход на правила при таймауте, ошибке или
  отказе модели, приоритет правил о подлоге фото (`test_ai_llm.py`, без сети).

## 🌟 Дополнительные возможности и преимущества MVP

1. **Автономная работа + необязательная языковая модель:**
   - По умолчанию вся логика работает на предприятии без внешних сервисов: онтология горнорудного оборудования, правила, стемминг, статистика.
   - С ключом `ANTHROPIC_API_KEY` проверка закрытия дополнительно использует Claude: языковая модель сравнивает описание проблемы с выполненными работами (6.2), мультимодальная — фото «до/после» и видимое качество (6.3). В модель уходят только технические тексты и фото оборудования, без ФИО. При таймауте, ошибке или отказе модели наряд проверяется правилами — закрытие не блокируется.
2. **Экспорт в Excel и печать в PDF:**
   - Полная поддержка ГОСТ/официальных форм наряда-допуска АО «Костанайские Минералы» с QR-кодами и блоками подписей.
   - Скачивание детальных отчётов в `.xlsx` со стилизованными шапками и автоподбором ширины столбцов.
3. **Раздел 7 кейса — Контроль списания ТМЦ:**
   - Автоматическое выявление перерасходов материалов свыше 40% от технологических норм.
4. **Голосовой ввод (Web Speech API):**
   - Диктовка неисправности мастером и отчёта рабочим прямо в цеху без снятия перчаток.
5. **Двуязычный интерфейс (RU / KZ):**
   - Мгновенное переключение языка интерфейса (русский / казахский) в один клик.
6. **Офлайн-индикатор и звуковой тестер:**
   - Наглядная индикация статуса сетевого подключения и переключатель звуковых сигналов с кнопкой проверки.

## ⚙️ Переменные окружения

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `DATABASE_URL` | SQLite `backend/naryad.db` | Например `postgresql+psycopg://user:pass@host:5432/naryad` |
| `DEMO_MODE` | `true` | `false` — скрыть быстрый вход и подсказку ПИН, закрыть `/api/auth/demo-users` |
| `JWT_SECRET` | встроенный (только для демо) | Обязателен при `DEMO_MODE=false` — иначе сервер не запустится |
| `PUBLIC_BASE_URL` | — | Адрес для телефонов, если IP определяется неверно (Docker, NAT) |
| `TELEGRAM_BOT_TOKEN` | — | Push-уведомления через Telegram-бота |
| `ANTHROPIC_API_KEY` | — | Включает проверку языковой и мультимодальной моделью Claude |
| `AI_LLM_ENABLED` | — | `false` — выключить модель даже при наличии ключа |
| `AI_LLM_MODEL` / `AI_LLM_EFFORT` / `AI_LLM_TIMEOUT_SEC` | `claude-opus-5-5` / `low` / `25` | Модель, глубина рассуждения и таймаут; при таймауте — проверка правилами |
| `DEADLINE_CHECK_INTERVAL_SEC` | `30` | Период проверки сроков ИИ-контролёром |
| `REMIND_BEFORE_MIN` | `30` | За сколько минут до срока напоминать исполнителю |
